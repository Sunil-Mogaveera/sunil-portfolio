# Sunil Portfolio Website

## Files
- `index.html` — website structure and content.
- `style.css` — visual design and responsive layout.
- `script.js` — menu interactions, form validation, and FormSubmit contact-form request.
- `profile.jpg` (if included) — profile photo used by the page.

## Preview
Keep all files in the same folder. Open `index.html` in a browser, or use VS Code with the Live Server extension.

## Publish on GitHub Pages
Upload the website files to the root of your repository, commit the changes, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Contact form
The form is configured to send messages to `sm6244@gmail.com` using FormSubmit. Email activation may be required, and successful delivery must be tested after activation. Opening the HTML locally does not guarantee email delivery.
